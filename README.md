# tristan-hotham.github.io

Personal hub for Dr Tristan Hotham, independent researcher: research on social media, campaigns and politics, interactive data studies of history and landscape, and free browser games.

Live at https://tristan-hotham.github.io/

Each project lives in its own repository and GitHub Pages site, for example `/famous-few/` or `/dale-down-fell-beck/`. This repository holds only the hub page. To add a project, add an entry to the `S` (studies) or `G` (games) array in `index.html`.
